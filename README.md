Ember Warden is an original 2D arena defence game: pilot a warden wisp, aim with the mouse, and hold the line against 10 waves of shadow creatures trying to snuff out the last ember. Between waves, choose one of three upgrades. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
